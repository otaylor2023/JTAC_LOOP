COLLEN RULE · CF-1.3 · added 2026-05-02
Munition selection — primary heuristic
Target moving / movable
→ Use laser-guided (GBU-12, AGM-114, AGM-65L, APKWS) or laser-hybrid (GBU-54 LJDAM). IIR autonomous (AGM-65D) also acceptable. Avoid pure GPS — JDAM struggles on movers.
Target stationary / not movable
→ Use coordinate-based JDAM / GPS (GBU-31, GBU-38, GBU-39 SDB) provided coords are CAT I (≤10 m). Laser-guided is acceptable fallback when no GPS option or weather defeats GPS.
Verbatim from Collen: "if the target is moving or movable, use laser. If it's stationary and not movable, use coordinate-based JDAM or GPS." Encoded as Stage 0 movement gate in 02_munition_selection.yaml; applies a +0.20 score boost to the matching guidance family before final ranking.
Type 1 / 2 / 3 — what each means
  • Type 1: JTAC sees both target AND aircraft. "CLEARED HOT" each shot. Blocked for GPS bombs.
  • Type 2: JTAC uses drone as eyes. "CLEARED HOT" each shot. Default for our system.
  • Type 3: Multi-shot window. "CLEARED TO ENGAGE" once with restrictions. Needs commander pre-approval.
Self-defense override

If friendlies are taking effective fire, bypass NSL and ROE category checks. PID and airspace gates still apply. Per CJCSI 3160.01 p.D-3 + p.C-B-4 (taking fire from a Cat I protected entity is the only path that bypasses the Cat I block).
